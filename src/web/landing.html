Zero Trust Defense

The Three Architectural Invariants

Giving an LLM direct API access to corporate bank accounts or private keys is financial suicide. CFO-One decouples intelligence from execution.

TIER 01

"LLM Extracts, Code Decides"

The AI acts purely as an extraction engine, translating messy unstructured invoices into structured JSON. It is never given deciding authority. Deterministic code tests for duplicate invoices, creeping price inflation, and imperative prompt injection directives.

TIER 02

Intel TDX Enclave Enforcement

Private credentials never touch the AI. Bank API tokens and signing keys are sealed inside an Intel TDX hardware enclave. The enclave physically refuses any single payment exceeding $1,000, and emits a cryptographic remote attestation quote for every decision.

TIER 03

Bank Detail Decoupling

The agent never pays the bank account printed on an invoice. Inbound invoices are diff-checked against pre-approved Airwallex beneficiaries. If an attacker swaps bank routing details on a real vendor invoice (BEC), the transaction is blocked immediately.
